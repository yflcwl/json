# 画布操作规范

## 画布与组件

- 组件类型：button / text / card / heading / tag / divider
- 组件标识是 data-id（短 id）；aria-label 格式为「类型：内容」（含连续空格，精确匹配、大小写敏感）
- 定位组件用 `.canvas-component[data-id="..."]`；card 有 strong（标题）+ p（描述）两个文字节点
- 坐标一律用画布数据坐标（1920 坐标系），不使用屏幕像素，也不假定画布尺寸固定

## 确认现状

- 先确认目标画布，读取当前尺寸、组件列表以及相关组件的位置、大小和内容。
- 有多个同名或外观相同的组件时，结合组件标识、位置和内容区分；仍不能确定时，先向用户确认。

## 执行编辑

- 每一步只做一项修改。有依赖的修改按顺序执行；画布尺寸改变后，重新读取状态再继续定位。
- 遇到组件遮挡，优先处理本次本来就需要修改且未被遮挡的组件，之后重新确认位置。不要为了绕开遮挡擅自移动无关组件。
- 操作失败后，先确认修改是否已经生效，再根据可确认的原因调整后重试。不要原样重复失败的操作。

## 复核与保存

- 编辑后重新读取画布，对照用户要求核对受影响组件的位置、尺寸、内容或数量。
- 画布会自动保存，无需额外保存。确认前端显示「已保存到服务端」后，才报告已保存。如果只能确认画布已更新，就明确说明保存状态未确认。
